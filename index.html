RAG Deep Dive · Retrieval Augmented Generation
Student Write-Up
RAG
THE RETRIEVAL-AUGMENTED GENERATION
What Is RAG?

Retrieval-Augmented Generation (RAG) combines the power of large language models with external knowledge bases. Instead of relying solely on training data, RAG systems retrieve relevant information at query time to generate more accurate, context-aware responses.

How RAG Works

1. Index: Documents are chunked and embedded into vectors.
2. Retrieve: Query matches most relevant context from DB.
3. Augment: Retrieved context feeds the LLM prompt.
4. Generate: Model produces grounded, accurate output.

60%

Knowledge Access
THE ENGINEERING MIDDLE LAYER
Vector Databases

Pinecone, Weaviate, Chroma, and pgvector store embeddings for fast similarity search.

Embedding Models

BGE, sentence-transformers, and OpenAI embeddings convert text to semantic vectors.
